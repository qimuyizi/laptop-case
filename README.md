很高兴我的成果可以给你带来帮助，但是在此之前，你需要知晓以下内容：
1.这个模型在设计时依据的是我手边已有的材料。这导致了模型通用程度极低。如果你不会任何有关建模的技能，那么此作品大概率是会浪费你的时间的
2.此模型在设计时没有考虑内部走线。装配时请务必做好抗干扰
3.模型在这几天的使用时已经暴露出些许问题，如下。

已知缺陷：
1.侧边笔记本托架的挡板可能不够高，上传时已经增高一点了，但还是建议根据实际再次加高
2.内置的5cm风扇可能较吵
3.由于最上层虽然为半开放，但是显卡背面仍旧有可能有较高温度
4.每款显卡长度不同，可能需要在背部预留较大空间
5.笔记本在开机时需要取下来开完机再接线。可以使用weak on lan或者休眠替代关机解决这一问题。
6.弹出硬盘时可能提示占用

如果你决定以此为参考，那么以下信息有可能对你有帮助：
1.在第一层安装电源时，推荐使用直角接口的电源线，电源线最少1m
2.安装时使用热熔胶进行固定
3.第二层左侧是给我的酷态科10号充电头以及双孔电源延长线预留的位置，可以改为你的充电头或者直接删除，务必记得加装散热片和5cm风扇和垫好导热垫
4.硬盘盒是把尾部直接切开的，具有破坏性，请三思
5.请在拔出硬盘前弹出硬盘。不要热插拔！不要热插拔！不要热插拔！
6.如果硬盘在弹出前显示占用，可以参考以下命令断开连接（使用管理员权限运行）
    diskpart
    list disk
    select disk (外接硬盘编号)
    offline disk
    online disk
7.请使用耐热材料打印，尤其是第三层，推荐petg。
8.装配时务必确认打印件的静电已经释放。
